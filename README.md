🕒 Stopwatch Web App Documentation
📄 Description
This project is a simple Stopwatch web application built using HTML, CSS, and JavaScript. It allows users to start, stop, and reset a stopwatch timer that tracks minutes, seconds, and milliseconds (in hundredths of a second).

🌐 Technologies Used
HTML: Structure of the app

CSS: Styling and layout

JavaScript: Timer logic and interactivity

🧱 HTML (index.html)
Defines the structure of the stopwatch with a display and three buttons:

Elements:
.stopwatch: Container for the stopwatch display.

.timerDisplay: Displays the time in the format MM : SS : MS.

Buttons:

#startBtn: Starts the timer.

#stopBtn: Stops the timer.

#resetBtn: Resets the timer.

🎨 CSS (style.css)
Features:
Centered Layout using Flexbox

Responsive Design for various screen sizes

Custom Color Buttons using CSS variables (--clr)

✅ How It Works
Click Start: Timer begins.

Click Stop: Timer pauses.

Click Reset: Timer resets to 00 : 00 : 00.

Track time for study sessions.
